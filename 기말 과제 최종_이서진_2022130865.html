여행 개요

목적지를 입력하고 검색을 누르면 현재 날씨가 표시됩니다. 이심·보험 광고 배너도 자동으로 나타나요.

출발일·도착일을 설정하면 일정표가 자동 생성됩니다.

준비물 체크리스트에 항목을 추가하고 클릭해서 완료 표시할 수 있어요.

📅
일정표

날짜별로 일정이 자동 생성됩니다. + 추가 버튼으로 행을 늘릴 수 있어요.

시간, 활동명, 메모를 직접 입력하세요. 날짜 헤더를 클릭하면 접고 펼 수 있어요.

인쇄 / PDF 저장은 상단 🖨️ 버튼을 누르세요.

📍
지도 탐색

검색창에 장소를 입력하면 OpenStreetMap에서 실제 결과를 가져옵니다.

빠른 검색 버튼(호텔·맛집·카페 등)으로 목적지 + 카테고리를 한번에 검색할 수 있어요.

검색 결과를 클릭하면 지도가 해당 위치로 이동합니다.

최상단 광고 슬롯은 파트너 업체 연결에 활용됩니다.

💌
타임캡슐

먼저 사이드바 하단에서 여행 멤버를 추가하세요.

출발 전에 5가지 질문에 멤버별로 답변을 작성하고 저장을 누르세요.

여행이 끝난 후 🔓 열기를 누르면 모든 답변이 한번에 공개됩니다!

다시 작성하려면 "다시 작성하기" 버튼을 누르세요.

📷
포토 앨범

업로드 영역을 클릭하거나 사진을 여러 장 한번에 선택할 수 있어요.

사진은 날짜별로 자동 그룹화되고, 한 행에 5장씩 정사각형으로 표시됩니다.

각 사진의 시간과 캡션을 수정할 수 있어요.

앨범 내보내기를 누르면 HTML 갤러리 파일로 저장됩니다.

💸
비용 정산

결제자 이름, 내역, 금액을 입력하고 추가를 누르세요.

결제자 이름을 입력해야 정산 계산이 가능합니다.

🤝 정산 계산하기를 누르면 누가 누구에게 얼마를 보내야 하는지 자동으로 계산됩니다.

🔗
공유 & 내보내기

링크 생성을 누르면 여행 데이터가 URL에 압축돼요. 링크를 받은 사람은 읽기 전용으로 열람 가능합니다.

텍스트 복사로 카카오톡에 바로 붙여넣기 할 수 있어요.

인쇄/PDF 저장도 지원합니다.

👥
여행 멤버

사이드바 하단 입력창에 이름을 입력하고 + 또는 Enter를 누르세요.

멤버를 추가해야 타임캡슐과 비용 정산 기능을 제대로 활용할 수 있어요.

멤버 태그의 ✕를 눌러 삭제할 수 있습니다.
